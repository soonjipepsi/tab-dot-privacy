1. 이 방침의 범위

이 개인정보처리방침은 jisun lee가 제공하는 Chrome 확장 프로그램 Tab Dot 0.4.11에 적용됩니다. Tab Dot은 같은 Chrome 프로필의 일반 창에서 실제로 사용한 탭을 최대 5개 골라 파비콘에 표시하고, 목록에서 그 탭으로 돌아가도록 돕습니다.

이용 기록은 사용자의 브라우저에서 처리합니다. Tab Dot은 이용 기록을 받는 제품 서버, 사용자 계정, 외부 분석 도구를 운영하지 않습니다. 아래에 설명한 아이콘 이미지 요청과 페이지에 보이는 표식은 별도로 발생할 수 있습니다.

2. 처리하는 정보

열린 탭의 현재 주소·제목·사이트 이름·파비콘 정보, 탭과 창 식별자, 활성 탭·창 포커스·최소화·잠든 탭 상태를 Chrome에서 확인합니다. 이 정보는 지원 대상 판별, 목록 표시, 현재 문서 확인, 아이콘 처리와 탭 이동에 사용합니다.

전면 활성 탭의 이용 구간·시간·방문 횟수·최근 이용 시각과 관련 집계·계산값, 순위, 아이콘 적용 상태를 처리합니다. Chrome이 알려 주는 활동·유휴·잠금 상태를 사용하며, 다른 앱의 이름이나 내용을 읽지는 않습니다. 원본·합성 아이콘 이미지와 문서 검증용 식별값·해시를 임시로 보관할 수 있습니다.

언어, 표시 색상·방식, 일시정지 여부를 설정으로 저장합니다. 현재 주소와 제목은 실행 중 확인하지만 원문 주소·제목의 방문 이력 목록을 별도 저장하지 않습니다. 현재 페이지 주소의 해시는 문서 검증에 사용하며, 해시를 익명 정보라고 간주하지 않습니다.

3. 이용 목적과 측정 범위

정보는 많이 사용한 탭을 고르고, 해당 사이트 아이콘에 표식을 적용·복구하며, 목록에서 탭으로 이동하는 기능에만 사용합니다. 중요도·생산성·성향을 평가하지 않습니다.

실제로 포커스된 일반 Chrome 창의 활성 탭만 집계합니다. 5초 미만 방문과 다른 앱 사용·최소화·유휴·잠금 시간은 제외합니다. 유휴 기준은 5분이며 실제 시선이나 집중 정도를 측정하지 않습니다. Chrome 내부 화면·시크릿 창·PDF 등 지원 제외 화면은 집계하지 않습니다.

웹페이지 본문, 입력한 글, 키 입력·스크롤 내용, 비밀번호, 쿠키, 결제 정보, 개인 메시지를 수집하는 기능은 없습니다. 페이지에서 읽는 정보는 현재 주소와 아이콘 링크 등 기능에 필요한 메타데이터이며, 팝업에는 Chrome이 제공한 현재 탭 제목이 표시됩니다.

4. 저장 위치와 보관·삭제

이용 집계·진행 구간·순위·아이콘 적용 상태와 일부 원본 아이콘 캐시는 Chrome의 실행 세션 저장소(storage.session) 및 확장 메모리에 보관합니다. 정산할 때 최근 최대 24시간의 분 단위 이용 기록을 사용하고 범위를 벗어난 시간 버킷을 제거합니다. 같은 탭에서 다른 페이지나 사이트로 이동해도 누적 시간은 이어지며, 이전 페이지별 이력은 만들지 않습니다.

탭을 닫으면 해당 탭의 기록을 삭제합니다. 브라우저 재시작, 확장 비활성화·재로드·업데이트 때 실행 세션 기록이 초기화됩니다. 서비스 워커의 일시적인 종료·재시작은 기록 초기화를 의미하지 않습니다. 내부 화면이나 PDF로 이동한 동안은 집계를 멈추고 같은 탭의 기존 누적 기록은 유지할 수 있습니다.

접근 권한을 잃은 탭의 기록·캐시는 삭제합니다. Chrome의 호스트 권한 철회 이벤트에서는 여러 사이트가 합산된 전체 이용 기록을 삭제합니다. 복구가 불가능한 잠든 문서 등에는 나중에 표식을 제거하기 위한 최소 탭 ID가 세션에 남을 수 있습니다.

일시정지는 기록을 유지합니다. 정지 중에는 시간 버킷을 계속 정산·만료시키지 않으며, 재개할 때 실제 경과 시간에 따른 최근 24시간 범위를 다시 적용합니다. 언어·색상·표시 방식·일시정지 설정은 storage.local에 보관되어 재시작 후에도 유지되고, 확장을 삭제하면 제거됩니다. Tab Dot은 storage.sync를 사용하지 않습니다.

5. 네트워크 요청과 페이지에서 보이는 정보

Tab Dot은 이용 시간·순위·기록표를 개발자나 분석 서버로 업로드하지 않습니다. 원본 파비콘을 읽기 위해 현재 페이지가 지정한 아이콘 서버(사이트 또는 CDN)에 이미지 요청을 보낼 수 있으며, 아이콘 링크가 없는 페이지에서는 같은 사이트의 /favicon.ico를 요청합니다. 일부 원본은 Chrome의 로컬 파비콘 조회 기능으로 가져옵니다.

확장이 직접 보내는 원본 이미지 요청은 자격 증명·Referer를 제외하고 리디렉션을 거부합니다. 그래도 요청 대상 서버는 IP 주소·요청한 이미지 주소 등 일반적인 접속 정보를 받을 수 있습니다. 아이콘 주소에 사이트가 넣은 식별 정보가 포함될 수도 있습니다. 원본 복구를 위해 페이지에 잠깐 추가하는 icon link의 로드는 브라우저와 사이트의 일반 규칙을 따르며, 직접 요청과 동일하게 쿠키·Referer가 제외된다고 보장하지 않습니다. 원본 URL이 HTTP이면 HTTP 이미지 요청이 발생할 수 있습니다.

합성 파비콘과 확장 소유 icon link는 페이지에서도 볼 수 있습니다. 따라서 해당 사이트가 상위 5개 선정 여부와 표시된 순위 구간(선택한 모드에서는 개별 순위)·색상을 추론할 수 있습니다. 합성 이미지에 정확한 이용 시간·점수나 사용자·탭 식별자는 넣지 않습니다.

6. 권한과 접근 제한

tabs는 열린 탭의 주소·제목·파비콘 정보 확인에, storage는 기록과 설정 저장에, scripting은 최상위 HTML 문서 확인과 아이콘 링크 적용·복구에 사용합니다. favicon은 Chrome에 있는 원본 아이콘 조회에, idle은 유휴·잠금 시간 제외에, alarms는 1분 정산에 사용합니다.

HTTP/HTTPS 사이트 접근은 사용자가 방문하는 여러 사이트에서 자동으로 아이콘을 처리하는 데 사용합니다. 이 권한 자체가 아이콘에만 한정되는 것은 아니며, Tab Dot의 실제 처리를 위 범위로 제한합니다. 세션·설정 저장소는 신뢰한 확장 컨텍스트만 접근하도록 설정합니다.

7. 사용자가 제어하는 방법

팝업의 ‘잠시 멈춤’은 측정·재계산·표시를 함께 멈추고 접근 가능한 문서의 원본 아이콘을 복구합니다. 기록은 유지되며 ‘다시 시작’으로 재개할 수 있습니다. 잠든 탭은 표시 갱신 때문에 깨우지 않고 복귀할 때 처리합니다.

Chrome 확장 설정에서 사이트 접근을 제한하거나 확장을 비활성화·삭제할 수 있습니다. 실행 기록을 초기화하려면 확장을 비활성화 후 다시 활성화하거나 브라우저를 재시작할 수 있습니다. 삭제는 저장된 설정도 제거합니다. 권한을 먼저 철회하거나 즉시 삭제하면 기존 문서의 원본 아이콘을 복구할 기회가 없을 수 있으므로, 가능한 경우 먼저 ‘잠시 멈춤’을 사용해 주세요. Tab Dot은 사용자의 브라우저 방문 기록·북마크·일반 캐시를 삭제하지 않습니다.

1. Scope

This privacy policy applies to Tab Dot 0.4.11, a Chrome extension provided by jisun lee. Tab Dot identifies up to five most-used tabs across normal windows in the same Chrome profile, highlights their favicons, and lets you return to them from a list.

Usage records are processed in your browser. Tab Dot has no product server that receives those records, user accounts, or external analytics. Icon image requests and page-visible highlights can occur as described below.

2. Information processed

Tab Dot reads current open-tab URLs, titles, site names and favicon information, tab and window identifiers, and active-tab, window-focus, minimized and sleeping-tab states from Chrome. These support eligibility checks, the list, document validation, icon handling and switching tabs.

It processes foreground usage intervals and time, visit counts, recent-use timestamps, related aggregates and calculations, ranking and icon-application status. It uses Chrome's active, idle and locked signals without reading other apps' names or content. Original and composed icon images, document identifiers and validation hashes may be cached temporarily.

Language, highlight color and style, and pause state are saved as preferences. Current URLs and titles are read during operation, but Tab Dot does not save a separate browsing-history list of raw URLs or titles. A hash of the current page URL is used for document validation; hashing is not treated as anonymization.

3. Purpose and measurement scope

Information is used only to select most-used tabs, apply and restore favicon highlights, and switch to a tab from the list. Tab Dot does not assess importance, productivity or personal characteristics.

Only the active tab in a focused, non-minimized normal Chrome window is counted. Visits shorter than five seconds and time in other apps, minimized windows, idle or locked states are excluded. The idle threshold is five minutes; actual gaze or attention is not measured. Unsupported surfaces such as Chrome internal pages, incognito windows and PDFs are not counted.

There is no feature to collect page body text, typed text, keystroke or scroll content, passwords, cookies, payment information or private messages. Page access reads metadata needed for the feature, such as the current URL and icon links; the popup displays current tab titles supplied by Chrome.

4. Storage, retention and deletion

Usage aggregates, the current interval, ranking, icon state and some original-icon cache data are kept in Chrome's session storage (storage.session) and extension memory. Recalculation uses minute buckets from up to the latest 24 hours and removes older time buckets. Time stays with the same tab across pages and sites; no per-page history is created.

Closing a tab deletes its record. Session records reset when the browser restarts or the extension is disabled, reloaded or updated. A temporary service-worker stop and restart does not itself clear the records. Moving to an internal page or PDF stops counting while the same tab's existing totals can remain.

Records and caches for tabs that lose access are deleted. A Chrome host-permission removal event clears all aggregated usage records because totals can span multiple sites. Minimal tab IDs may remain in the session to restore highlights later on documents that cannot currently be accessed, including sleeping tabs.

Pausing keeps the records. Time buckets are not continuously recalculated or expired while paused; the actual elapsed time and 24-hour window are applied again on resume. Preferences in storage.local survive restarts and are removed when you uninstall the extension. Tab Dot does not use storage.sync.

5. Network requests and information visible to pages

Tab Dot does not upload usage times, rankings or record tables to the developer or an analytics server. It may request an original favicon from the icon server declared by the current page, including a site or CDN, or from the same site's /favicon.ico when no icon link is declared. Some originals are obtained through Chrome's local favicon lookup.

Direct icon fetches made by the extension omit credentials and the Referer header and reject redirects. The destination server can still receive ordinary connection information, such as your IP address and the requested image URL; a site may include identifiers in that URL. Loading a temporary icon link to restore the original follows ordinary browser and site rules and is not guaranteed to omit cookies or referrers like direct fetches do. HTTP image requests can occur when the original URL uses HTTP.

The composed favicon and extension-owned icon link are visible to the page. A site may therefore infer selection in the top five, the displayed rank group (or individual rank in the selected mode), and highlight color. Composed images do not contain exact usage time, scores, or user or tab identifiers.

6. Permissions and access controls

The tabs permission supports reading open-tab URLs, titles and favicon information; storage saves records and preferences; scripting checks top-level HTML documents and applies or restores icon links. favicon accesses original icons held by Chrome, idle excludes idle and locked time, and alarms schedules the one-minute check.

HTTP/HTTPS host access enables automatic icon handling across sites you visit. This permission is not inherently restricted to icons; Tab Dot limits its actual processing to the scope described here. Session and preference storage are configured for access only by trusted extension contexts.

7. Your controls

Pause in the popup stops measurement, recalculation and highlighting together and restores original icons in accessible documents. Records remain and Resume restarts operation. Sleeping tabs are not awakened for automatic icon updates; pending work is handled when they return.

You can restrict site access, disable or uninstall Tab Dot in Chrome's extension settings. Disable and re-enable the extension, or restart the browser, to reset session records; uninstalling also removes preferences. Revoking access or uninstalling immediately may prevent restoration in existing documents, so use Pause first where possible. Tab Dot does not delete your browser history, bookmarks or general browser cache.

8. Limited Use

Tab Dot follows the Chrome Web Store User Data Policy and its Limited Use requirements. Information is used only to provide the described tab-finding feature, not sold or used or transferred for advertising targeting, unrelated profiling, creditworthiness or lending decisions. There is no feature that automatically sends usage records to the developer for inspection.
